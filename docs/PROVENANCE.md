# Repository provenance

The current public repository is
[`starboytiimz/procuresettle`](https://github.com/starboytiimz/procuresettle).
Its Git history preserves the project's earlier repository name, LineSettle.
The product rename was committed as `17a891784f940446cd3a2eefef37ff7139d98270`
(`chore: rename LineSettle to ProcureSettle and add license`). Commit history
was not rewritten.

The earlier project identity was itself introduced by commit
`56b360aa9a2ea0adef3943cdbe079602eb61994a` (`chore: rename project to
LineSettle`). The settlement core predates that naming commit in the same
history. These commits document names and repository identity; they should not
be read as evidence of development outside the history available here.

Evidence records retain the exact repository URL, source commit, source tree,
WASM name, and digest associated with each run. The hosted Stage 6 record was
produced while the project was called LineSettle; later Stage 9, local, Testnet,
and Movix records use ProcureSettle where applicable. A later name change does
not change the producer identity or artifact hash of an earlier run. See
[`docs/EVIDENCE.md`](EVIDENCE.md) and each bundle manifest for those identities.

The Movix repository is an independently maintained project. Its pinned source
was inspected for a bounded read-only compatibility exercise. No shared
repository, code integration, maintainer review, endorsement, adoption, or
operational relationship is established by that exercise.
